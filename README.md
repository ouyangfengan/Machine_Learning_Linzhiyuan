# Machine_Learning_Linzhiyuan

本仓库是《统计方法与机器学习》Lab 01 课程作业使用的**演示仓库**，仅用于说明套磁信中提到的项目仓库地址，不是真实的研究项目。

## 仓库作用

Lab 01 的任务是用 AI Agent / AI Coding 工具为一位虚构学生准备研究生联系信（套磁信），并提交过程材料。信中出现了学生项目仓库地址，本仓库就是该地址对应的占位仓库，作用是：

- 让信件中的仓库链接指向一个真实存在、可访问的地址，而不是无效链接；
- 说明信件中的个人经历、项目规模与实验结果均为课程创作设定，不对应任何真实数据。

## 重要声明

- 信中的学生「林致远」及其学校、成绩、项目分工、实验数字、实习与技术报告等，**全部是课程演示用的虚构设定**，不代表任何真实人物或真实实验结果。
- 本仓库内**不包含**任何真实的训练脚本、数据集、模型权重或评测结果，只有这份说明。
- 教师与论文信息来自公开来源的核查，可参见作业包中的检索与证据记录。

## 作业背景

- 课程：统计方法与机器学习
- 作业：Lab 01
- 内容：AI 辅助的联系信撰写流程、可复用 Skill、以及基于自建 DBLP MCP 的真实文献检索与证据审计

本仓库仅作课程演示用途。
